# 从方向到值得记住的瞬间

适用于八类场景的自主创作和表现力提升。先沿 [导演前期方法](director-method.md) 确定观众变化与主线，再用下面的方法找到更有表现力的做法。简单任务只记录关键选择，不必另建一套文件；复杂任务沿 [方向模板](../templates/direction.md) 展开。

## 自主创作要留下可检查的判断

在本次授权、事实、不可变素材和资源范围内，由Agent研究、比较、选择并推进；用户未要求评方向时不逐项停等。要求写为“行动 → 决定或产物 → 依据 → 验法 → 不成立时的调整”，可整合在现有计划或笔记，不强制五份文件。

先区分材料明确表达的内容、解释性推断和创作隐喻，确定主题、观众变化与关键转折。隐喻不冒充作者原意、新闻事实或产品能力；既有作品可以作为起点，不必锁死新方向。

## 参考要能指出差距

先提出尚未解决的创作问题，再选择相关作品、用户已有资产或观众语境。研究应解决如“怎样让关系可见”“什么构图适合这段情绪”的具体缺口；判断有足够依据后停止搜索。需要当下传播语境时再核当前讨论，不默认追逐所有热点。

每张参考卡记录：

| 项目 | 记录什么 |
| --- | --- |
| 来源与范围 | 原始入口、版本或文件、实际观察的时间段；只读源码、抽帧、连续观看、试听分别注明 |
| 表达目的 | 该段让观众注意、理解或感受到什么 |
| 观察证据 | 哪个具体动作、构图、声画关系支撑判断；来源自述与亲眼观察分开 |
| 可迁移关系 | 例如“先给全貌，再沿同一对象推近证据”；先讲关系，再选技术 |
| 当前差距 | 本片哪镜信息不清、能量不变、缺少后果或衔接；不可只写“不够高级” |
| 验收办法 | 哪个状态应可读、哪处应连续、哪次实际看听比较能判定；尚未检查就记待验 |

缩略图、帧差或波形帮助找切点和候选问题；回到原尺寸片段与实际声音确认。不能从源码、成片属性或作者宣称推导“同类最好”。提炼原则，不照搬来源的版式、画面、角色、音乐或品牌。

## 比较方向，写清审美边界

复杂开放任务可比较少量实质不同的方向，按切题、观众、辨识度、真实实现能力和资源自行选择并留取舍。风格名称应能推导构图、光线、材质、文字、运动和声音的做法，不能只造术语；不固定要求两三案。

写“希望形成的感受 → 能看见／听见的选择 → 可观察失败 → 修正动作”。例如需要轻松清晰的产品感，可检查结果是否被繁杂背景遮住、提示音是否抢过解释，再按问题简化和换音色；不能只写高级或禁AI味。逐镜用本片边界检查，也允许有理由的反差和变奏。

未知能力先按 [镜头生产统筹](shot-production.md) 用当前说明和最小试验判断。不因不熟悉而提前降低创意，也不因乐观就宣称工具支持。新鲜感、传播愿景与已证实效果分开，不能承诺爆款。

## 先描述关键事件，再选择效果

按任务规模提出一到三个值得记住的瞬间。先不用特效名称，写出“之前是什么 → 发生什么 → 之后是什么 → 观众因此得到什么”。方向有实质差异且选择会影响整片时，再提出少量备选并给选择理由；不固定每次先交三案或停等。

例如产品片：“散落的三项请求被送入同一任务入口，处理后的结果各自归位，观众看到一次操作怎样完成整个任务。”这只是表达设想；真实产品不支持该流程时，应改成有证据的任务，不能用动画造能力。

每个瞬间关联已有镜头、故事节拍、关键实体与真实依据，说明前后状态、视觉焦点、声音职责和下一镜接力。记录在方向文字或现有导演计划中；这些文字不是新增可执行字段，不要自行改造计划合同。

## 让母题随着内容改变

贯穿物可以是请求卡、一个词、光线、形状、空间关系或声音动机。每次出现应推进意义：从问题到操作、从操作到结果，或从陌生到熟悉。只重复颜色和装饰无法承担主线。

接力可沿位置、尺度、方向、形状、视线或声音完成。需要无缝交接时检查切点两侧的主体、坐标、速度和遮挡；语义转换时也允许明确切换、静默或停留。固定舞台能帮助比较，重复版式也能建立规则；不为变化而打断理解。

## 主运动与次级响应

先选一个本镜最重要的事件，其余动作按因果错开。可按下面顺序试排，再根据内容删减：

| 阶段 | 导演判断 |
| --- | --- |
| 预备 | 观众是否已找到动作对象；预备动作是否必要 |
| 主运动 | 谁改变了什么；相机或主体谁承担主要运动 |
| 次级响应 | 标签、背景、跟随物怎样回应，避免所有层同起同停 |
| 落定与阅读 | 结果、文字、空间关系有足够时间被看清 |
| 退场与接力 | 下一镜怎样接住信息、方向或声音；尾音与遮挡怎样结束 |

同一时段、同一属性明确控制者，避免场景动画与相机同时争夺位置或缩放。缓动、弹性、弧线、运动模糊按材质、尺度和表达目的选择；不强制每个界面弹跳或每次出场都加速。静止可以服务阅读和情绪，微动不能损害文字稳定。

## 声画谁领拍，由内容决定

旁白主导时先量真实台词；音乐表演主导时先定乐段和重音；产品演示主导时先锁触发、反馈和结果。它们共享语义事件，再落到已有绝对时间与素材源时间，不另造竞争时钟。主次运动和声音可以有意错开，但须有表达理由与实际检查。详见 [声音与节奏](sound-and-rhythm.md)。

先检验关键片段的纯音频或粗混，再结合画面核对因果和注意力；没有实际回听能力时明确保留听审缺口，不因方案写完就判舒服。完整音乐、局部音效和静默都可使用，不规定每次切镜都配嗖声。

## 创作类型与生产选择

| 参考提示词的类型 | 在现有场景中的用法 |
| --- | --- |
| showreel | 手艺或视觉母题主导，可选 music-visual／brand-film；围绕发展中的核心创意组织 |
| product | 产品任务主导，用 product-demo／feature-motion，真实操作要有可见后果 |
| launch-story | 有人物事件时用 story-video；产品发布按 product-demo／brand-film 目的选择 |
| explainer | 知识用 knowledge-explainer；事件更新用 news-brief；先明确一条主要关系 |

这四种只是方向描述，不新增场景ID，也不替代 `plan.mode` 的 recipe／compose／free。给定图片仍可沿 image-story。用户要求、品牌约束与实际事实决定取舍，不把参考提示词变成套件强制规则。

代码制作可提供可编辑组件和确定性时间；截图、录屏、生成画面、现有工程也有各自适用任务。选最能保真和兑现意图的路线，不强制代码重建所有素材或排除生成画面。制作规格、素材版本、短样片与画幅适配按 [执行与交付](runtime-and-delivery.md) 处理。

## 关键表达要在成片兑现

将主线承诺的重要变化关联到已有scene／element／beat和实际片段：产品的触发与结果、知识的条件与因果、故事的行动与后果、品牌母题的发展、音乐的段落与释放。每个关键点写预期变化、实际声画依据和未兑现处；有意克制时说明理由。不要求每个拍点都加效果，也不强制每片反转。

## 对照、修改、停止

把关键瞬间放回参考卡的具体目标，核查差距是否缩小。先修影响事实、理解、阅读、听感或连续性的最大问题，再处理装饰。审片记录按 [审片与修改](review-and-revision.md) 留时间点、证据、修改和复验，区分独立评审与自检。

开始前按用户范围、风险和资源写探索上限与停止条件。达到必需验收后交付；资源上限先到则保留最好的实际版本、未达目标和原因，不无限循环，也不将“已运行检查”写成审美通过。

方法来源：用户于2026-10-18提供的动效导演提示词，作者与公开发布页未知。本参考为经确认范围内的原创适配，保留其参考对照、关键瞬间、主次运动和证据返修思想；不照收固定镜头间隔、全片冻结限制、固定响度／帧率、每镜新评审或全代码制作等要求。
